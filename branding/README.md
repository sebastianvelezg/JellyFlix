# Jellyflix branding

The Jellyflix **name, logo (the jellyfish) and wordmark** belong to this project and identify it, and only it.

- The artwork was created by the project's author with AI image tools.
- The MIT license of this repository covers the **code**, not the name or the artwork. You may share screenshots and link to the project, and say that
  something works with Jellyflix.
- If you fork the code and distribute your own build, give it **its own name and its own logo**, and do not suggest that it is Jellyflix or that it is endorsed
  by this project.

## Files

| File | What it is |
|---|---|
| `source/jellyflix-icon.png` | The jellyfish logo, as made (square, on a grey glow) |
| `source/jellyflix-wordmark.png` | The word "JellyFlix" on black |
| `banner.png`, `social-preview.png` | README header and the GitHub link-preview image |
| `make_assets.py` | Makes every icon size for the web and TV apps from the two source images (`pip install pillow numpy`, then `python branding/make_assets.py`) |
| `make_hero.py` | Composes `docs/screenshots/hero.jpg` (the README's main picture) from three screenshots in `docs/screenshots/` |
